# Editor-fotos

**Estudio de Imágenes**: una página web (un solo archivo, `index.html`) para transformar fotos con IA usando la red gratuita de voluntarios [AI Horde](https://aihorde.net) (img2img).

## Cómo usarla
1. Abre `index.html` en el navegador (o publícala en GitHub Pages / Vercel).
2. Elige una foto, describe el cambio (mejor en inglés) o toca un estilo.
3. Ajusta cuánto cambiar y la cantidad de imágenes, y pulsa **Generar imágenes**.

Opcional: crea una clave gratis en [aihorde.net/register](https://aihorde.net/register) para tener prioridad en la fila.
